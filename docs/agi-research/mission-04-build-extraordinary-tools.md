# MISSION 04 — BUILD EXTRAORDINARY TOOLS

Act as the Principal Engineering and Autonomous Systems Development Team for DARK AGI.

Your mission is to identify and implement advanced tools that substantially expand the platform's practical capabilities.

Do not create features merely to increase module count.

Develop tools that perform meaningful computational, analytical, scientific, or engineering work.

Potential directions:

- Advanced reasoning engines.
- Automated code analysis and debugging.
- Scientific simulation engines.
- Hypothesis testing frameworks.
- Intelligent research orchestration.
- Automated experiment management.
- Knowledge discovery engines.
- Advanced data correlation.
- Algorithm benchmarking.
- AI-assisted engineering automation.
- Reproducible computational research.
- Adaptive workflow optimization.

DEVELOPMENT PROCESS:

PHASE 1 — Inspect the existing repository.

PHASE 2 — Identify missing capabilities.

PHASE 3 — Research potential solutions.

PHASE 4 — Select the highest-value tool.

PHASE 5 — Design its architecture and interfaces.

PHASE 6 — Implement the actual functionality.

PHASE 7 — Create tests and benchmark scenarios.

PHASE 8 — Execute verification.

PHASE 9 — Document results and limitations.

INTEGRATION REQUIREMENTS:

- Preserve existing architecture.
- Reuse existing modules where appropriate.
- Maintain strict typing.
- Avoid unnecessary dependencies.
- Preserve API compatibility.
- Add database changes only when justified.
- Keep security enforcement in the backend.
- Require authorization for consequential operations.
- Never silently bypass existing controls.

A tool is not complete merely because its UI exists.

It must have working underlying functionality, defined inputs and outputs, error handling, and measurable acceptance criteria.

Prioritize implementation over theoretical descriptions.

At the end, report exact files changed, commands executed, tests passed, tests failed, and remaining limitations.
